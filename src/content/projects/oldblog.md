## About

Before having the current blog, this is my first project I've ever built. At that time, the only goal I set is to learn how web works, especially static site and how to do blogging. So, from that purpose, I choose Hugo as the SSG (Static Site Generator) as it is known for its beginner-friendly and its popularity. Since then, I've tried several hugo's themes, from [Papermode](https://themes.gohugo.io/themes/hugo-papermod/) to the latest one, which is [Blowfish](https://themes.gohugo.io/themes/blowfish/).

:::info

I apologize for not being able to give you guys the link to the blog.

:::

For your information, I'd been blogging with Hugo for about 3 years since I started it in 2023. Now, in 2026, it's officially stopped and fully migrated to the current site (this blog).
