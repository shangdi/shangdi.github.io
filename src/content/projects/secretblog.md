## About

This is my second personal project I've ever built in the internet, which is actually a continuation of the first one. As you might have guessed, this project is a personal blog. I've been using this blog for expressing my interests on technology, particularly things that are related to open source like [Linux](https://www.linux.org/). Besides, I've written other things that are not quite "open source" kind of things, such as Windows and CCTV.

Go explore this blog!  
In case you find this project interesting, you might want to [Support Me](http://localhost:4321/sponsor/).

### Technology behind this web

Honestly speaking, I don't develop this site from the ground. In fact, I use two primary technologies in order to achieve my goal: **"writing blog"**. Here are they:

- [x] [**Astro**](https://astro.build/) - as the base for web framework.
- [x] [**Firefly**](https://firefly.cuteleaf.cn/) - as the template. 

For further guidance, you can visit their official documentation:  
https://docs-firefly.cuteleaf.cn/en/

### What's coming

Because I mostly write a blog based on my mood and my interest, I won't give you any promise. Vice verca, I hope you won't expect too much from me. But, one thing I'm sure is that this blog will be still alive and updated as long as I'm alive and have enough time.

I have some plans on what to write too, so here are some you can expect from me:

- [x] **Linux and Open Source** - This is my kind of "top of mind" topic.
